# 📅 JAgenda — Aplicación de Agenda Personal
Una aplicación fácil de usar para gestionar contactos de manera sencilla. Una de las características que nos distingue es que permite determinar el tamaño de la agenda según las necesidades del usuario. Si no se especifica un tamaño, se establecen por defecto 10 contactos. 
# ✨ Funcionalidades
La aplicación cuenta con las siguientes opciones:
1. ➕ Añadir contacto
2. 🔎 Comprobar si existe un contacto
3. 📋 Listar contactos
4. 🔍 Buscar contacto
5.🗑️ Eliminar contacto
6. 📊 Comprobar si la agenda está llena
7. 📌 Consultar espacios disponibles
8. ✏️ Editar teléfono
9. 🚪 Salir
# 🛠️ Tecnologías utilizadas
   - Java
   - Java Swing (javax.swing)
   - TreeMap — utilizado para almacenar, ordenar y gestionar los contactos.
# 🧩 Estructura del proyecto
El proyecto está organizado de la siguiente manera:
## 📁 Models
Contiene las clases principales que representan la información y lógica de la aplicación:
### Agenda
  - Gestiona los contactos almacenados.
  - Permite agregar, consultar, buscar, editar y eliminar contactos.
  - Incluye validaciones relacionadas con la capacidad de la agenda.
### Contacto
  - Representa la información de cada contacto.
  - Contiene sus atributos y métodos para consultar y modificar sus datos.
## ▶️ Main
Contiene el punto de entrada de la aplicación e inicializa el programa y el menú principal.
# 🎯 Objetivo del proyecto
El objetivo de JAgenda es poner en práctica conceptos fundamentales de programación orientada a objetos en Java, como:
  - Clases y objetos
  - Métodos y atributos
  - Estructuras de datos
  - Validaciones
  - Manejo de colecciones mediante TreeMap
  - Interacción con el usuario mediante un menú
